## 커밋 컨벤션

```
<태그> : 간단한 설명
```

| 태그        | 설명                       | 활용 예시                        |
| ----------- | -------------------------- | -------------------------------- |
| ⚙️ Setting  | 개발 환경 및 프로젝트 설정 | Expo, NativeWind, ESLint 등 설정 |
| ✅ Test     | 테스트 관련                | 테스트 코드 작성 및 수정         |
| ✨ Feature  | 기능 개발                  | 새로운 화면, 기능 구현           |
| 🌍 CI       | 배포 및 CI/CD 관련         | GitHub Actions, EAS Build 설정   |
| 🪲 Fix      | 버그 수정                  | UI 오류, 기능 동작 오류 수정     |
| 📄 Docs     | 문서 작성 및 수정          | README, 프로젝트 문서 수정       |
| 🔧 Chore    | 자잘한 수정                | 패키지 업데이트, 파일 정리       |
| 🔨 Refactor | 코드 리팩토링              | 컴포넌트 분리, 코드 구조 개선    |
| 🎨 Style    | UI 및 스타일 수정          | 디자인, 레이아웃, 간격 수정      |

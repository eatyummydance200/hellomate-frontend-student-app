# 공통 컴포넌트 5종 구현 보고서

## 배경

Figma 디자인(`hellomate-workspace`)에서 반복되는 UI 패턴을 스캔해 원자 단위 공통 컴포넌트 5종(Text, Button, Input, Card, Avatar)을 구현했다. 사전에 로드맵(`docs/roadmaps/2026-08-15-피그마-공통-컴포넌트-로드맵.md`)을 먼저 설계해 순서와 원칙을 합의한 뒤 그 순서대로 진행했다.

## 구현 순서와 근거

의존성 기준으로 정렬: **Text → Avatar → Button → Input → Card**

- Text: 다른 4종이 전부 내부적으로 텍스트를 쓰므로 최우선
- Avatar: 완전 독립 컴포넌트
- Button / Input: 둘 다 Text에 의존, 서로는 독립
- Card: Text/Avatar 등을 조합해 쓸 가능성이 높은 컨테이너라 마지막

각 컴포넌트는 한 번에 하나씩, Figma 노드를 실제로 확인한 뒤 구현하는 방식으로 진행했다(`get_metadata`로 화면 스캔 → `get_design_context`로 개별 노드 확인 → `tailwind.config.js` 토큰과 대조).

## 컴포넌트별 구현 내용

### 1. Text (`src/components/Text.tsx`)
- `size`(micro/captionSm/caption/label/body/title/display) / `weight`(sans/medium/semibold/bold) / `color`(default/strong/muted/inverse/primary/danger) variant
- 기존 `tailwind.config.js` 토큰만으로 전부 커버되어 Figma 재조회 없이 구현

### 2. Avatar (`src/components/Avatar.tsx`)
- Figma 노드 24:495(커뮤니티/게시글 상세, 34px)와 24:3016(마이페이지, 48px)를 확인 → 동일한 플레이스홀더 아이콘의 두 사이즈로 판단, `size: 'sm' | 'lg'` variant로 반영
- 아이콘 자산을 `assets/icons/avatar-placeholder.svg`로 다운로드해 커밋
- **토큰 결정:** 배경색이 Figma에서 `#F5F5F5`인데 기존 토큰과 일치하지 않아 확인 → `background.circle` 신규 토큰 추가

### 3. Button (`src/components/Button.tsx`)
- Figma 노드 24:2033(CTA 버튼)과 24:2298/24:2301(이전/다음 분할 버튼)을 확인 → `variant: 'primary' | 'secondary'`
- `primary`는 `bg-primary` + `text-inverse`, `secondary`는 `bg-border-strong` + `text-default` — 둘 다 기존 토큰과 정확히 일치해 신규 토큰 없음
- `disabled`는 기본 Tailwind opacity 스케일(`opacity-40`)로 처리
- **보류:** outline 버튼("나가기")은 화면 1곳에서만 확인되어 YAGNI로 제외. 밑줄 텍스트 링크("인증 번호 재발송")는 여러 화면에 반복되지만 색상(`#575858`)이 토큰과 안 맞고 Button보다는 별도 컴포넌트에 가까워 범위 밖으로 판단

### 4. Input (`src/components/Input.tsx`)
- Figma "클럽 이름"(아이콘 없음, 24:939)과 로그인 ID/PW 필드(왼쪽 아이콘, 24:1916/24:1925)를 확인
- `label` / `required` / `error` / `leftIcon` prop으로 정리
- 박스 스타일(`border-border-strong`, `rounded-md`, `bg-background`, 56px 높이)은 모든 화면에서 토큰과 정확히 일치
- placeholder 색은 Figma의 `text-muted` 60% 투명도 값을 그대로 사용(`rgba(109,122,116,0.6)`) — RN `TextInput`의 `placeholderTextColor`는 className을 못 받아 하드코딩
- **토큰 결정:** 에러 메시지 색이 화면마다 3가지(`#f30707`/`#ba1a1a`/`#e56d6d`)로 달라 확인 → 기존 `danger` 토큰(`#f30707`)으로 통일
- **보류:** 비밀번호 눈 아이콘 토글, 인원수 스테퍼, 날짜 스피너는 특정 화면 1곳 전용 특수 위젯이라 제외. 체크박스로 보이는 "Input"이라는 이름의 노드는 실제로는 별도 Checkbox 컴포넌트(5종 목록 밖)라 무시

### 5. Card (`src/components/Card.tsx`)
- 컨테이너 셸만 담당 — children으로 내용을 조합하는 방식(Article/Club/Comment 카드 등 구체적 조합은 화면 구현 단계에서 처리)
- Figma "Article Card"(24:493, radius 16)와 "Club Join Card"(24:635, radius 20)를 비교 → 공통 셸(흰 배경+테두리+padding)은 같고 radius만 달라 `radius: 'lg' | 'xl'` variant
- **토큰 결정 2건:**
  1. 그림자 값이 `boxShadow` 카테고리 자체가 config에 없어 확인 → 그림자는 생략(테두리+배경만 사용)
  2. 카드마다 테두리색이 `#dee4e0`/`#bccac3`로 갈려 확인 → 기존 `border.strong` 토큰으로 통일(`border-border-strong/30`)

## tailwind.config.js 변경 사항

`colors.background.circle = '#f5f5f5'` 한 개 토큰만 신규 추가. 나머지는 전부 기존 토큰 재사용.

## 검증

5개 컴포넌트 모두 `npx tsc --noEmit` 통과 확인.

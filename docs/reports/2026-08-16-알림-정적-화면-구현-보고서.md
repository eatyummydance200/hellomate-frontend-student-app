# 알림 정적 화면 구현 보고서

## 배경

Phase 4(정적 화면 퍼블리싱) 다섯 번째 배치로, Figma `hellomate-workspace` 파일의 알람 화면 그룹(노드 `57:222`)에 속한 화면 전부를 API 연동 없이 더미 데이터로 하드코딩 구현했다. 그룹은 3개의 최상위 프레임(알림_채팅, 알림_알림, 알림_설정)을 담고 있었다.

| Figma 프레임 | 실제 구현 | 구현 파일 |
| --- | --- | --- |
| 알림_채팅 (24:1671) + 알림_알림 (24:1756) | 탭 전환 목록 화면 | `app/notifications/index.tsx` |
| 알림_설정 (24:1834) | 모달 화면 | `app/notifications/settings.tsx` |

## 화면 통합 판단

- **알림_채팅 / 알림_알림** → 두 프레임은 헤더·탭바·필터 태그 구조가 완전히 동일하고 "채팅"/"알림" 탭 활성 상태만 다른, 같은 화면의 두 상태였다. [[project_club_screens]]에서 확립한 원칙(탭 전환은 별도 라우트가 아니라 로컬 `useState`)을 그대로 적용해 `app/notifications/index.tsx` 하나로 합쳤다.
- **알림_설정** → 뒤로가기 대신 닫기(X) 아이콘이 있는 전체 화면이라 [[project_notice_screens]]의 "담당자 문의"(`notice/contact.tsx`)와 같은 `presentation: 'modal'`로 등록했다.

## 라우트 구조 변경

기존 `app/notifications.tsx`(자리표시자 텍스트만 있던 단일 파일, 루트 `app/_layout.tsx`에 `title: '알림'`로 네이티브 헤더 등록)를 삭제하고 `app/notifications/` 폴더로 전환했다:

- `app/notifications/_layout.tsx` — 커스텀 헤더를 직접 그리므로 네이티브 헤더 숨김, `settings`를 모달로 등록
- `app/notifications/index.tsx` — 진입 경로 그대로 `/notifications` 유지(폴더의 `index.tsx`가 동일 경로에 매핑되어 각 탭 화면의 벨 아이콘(`router.push('/notifications')`) 호출부는 수정 불필요)
- `app/notifications/settings.tsx`
- 루트 `app/_layout.tsx`의 `<Stack.Screen name="notifications" ... />` 등록도 제거 — notice/club/info 폴더와 동일하게 각자 `_layout.tsx`가 헤더를 담당하므로 루트에서 별도 등록할 필요 없음

## 화면별 구현 내용

### 1. 알림 (`app/notifications/index.tsx`)

- 헤더: 뒤로가기 화살표 + "알림" 타이틀 + 설정 톱니바퀴 아이콘(`/notifications/settings`로 이동)
- 채팅/알림 탭 전환(`useState`, 진입 시 기본값은 "알림" 탭 — 벨 아이콘을 눌러 들어오는 화면이라 알림 목록이 먼저 보이는 쪽을 기본으로 판단)
- 필터 태그: 채팅 탭(전체/1:1 문의/클럽 채팅), 알림 탭(전체/공지/커뮤니티/클럽/생활정보) — [[project_notice_screens]]의 "전체 공지사항" 필터와 동일하게 `useState` + `.filter()`로 실제 목록 필터링 동작
- 채팅 목록: 담당자 1:1 채팅 3건 + 클럽 그룹 채팅 2건(마지막 발신자 "Min-su:" 프리픽스는 초록색 강조), 안읽음 뱃지·그룹 채팅 아이콘 표시
- 알림 목록: "오늘"/"어제" 날짜 섹션으로 그룹핑, 카테고리 배지(공지/클럽) + 안읽음 여부(초록 점 또는 `opacity-50` 처리) + 클럽 알림에는 "채팅방 바로가기" CTA 버튼(Phase 4라 실제 이동 없음)

### 2. 알림 설정 (`app/notifications/settings.tsx`)

- 헤더: "알림 설정" 타이틀 + 닫기(X) 아이콘(`router.back()`)
- 채팅 알림(담당자 1:1 채팅/클럽 그룹 채팅) + 서비스 알림(공지사항/커뮤니티/클럽활동/생활 정보/시스템 안내) 두 섹션, 총 7개 토글
- 토글은 React Native 내장 `Switch` 컴포넌트 사용 — Figma 목업은 커스텀 PNG 토글 이미지였지만, 네이티브 플랫폼 컴포넌트가 이미 동일한 기능(on/off 애니메이션)을 제공하므로 별도 이미지 에셋 없이 `trackColor`로 브랜드 컬러만 맞춰 구현. 각 토글은 `useState`로 실제 켜짐/꺼짐 반영(전송 로직은 없음)
- "시스템 안내"는 Figma에서 "Fixed On"으로 항상 켜진 상태였으므로 `disabled` + `opacity: 0.5`로 고정

## 에셋

Figma MCP 에셋 URL에서 아이콘 2종을 새로 받아 커밋했다: `icon-settings-outline.svg`(헤더 톱니바퀴, `stroke` 색상을 기존 아이콘 관례에 맞춰 `#3D3D3D`로 통일), `icon-group-chat.svg`(클럽 채팅방 이름 옆 인원 아이콘). 뒤로가기 화살표와 닫기 아이콘은 기존 `icon-chevron-left.svg`(크기 9×17.34로 정확히 일치)·`icon-close.svg`를 그대로 재사용했다.

## 토큰 결정

새로 등장한 색상 다수가 기존 토큰과 정확히 일치했다: `primary`(`#006b55`), `primary.dark`(`#00503f`, 활성 탭 밑줄/텍스트), `primary.light`(`#49c9a7`, 안읽음 점), `text.strong`(`#171d1a`), `text.muted`(`#6d7a74`), `text`(`#3d4944`), `border`(`#dfdfdf`). [[project_notice_screens]]에서 확정된 방침대로, 일치하지 않는 값(비활성 탭 텍스트 `#8e8e93`, 비활성 탭 밑줄 `#c6c6cd`, 헤더 타이틀 `#3d3d3d`, 채팅 미리보기 `#1c1e1e`, 채팅 시간 `#8b8b8b`, 카드 구분선 `rgba(188,202,195,0.3)`, 필터 비활성 텍스트 `#6f6f6f`)은 기존 다른 화면에서도 이미 쓰인 값 그대로 인라인 임의값으로 처리했다. `tailwind.config.js`는 건드리지 않았다.

## 검증

- `npx tsc --noEmit` 통과 — 신규 라우트(`/notifications`, `/notifications/settings`)가 타입에 처음엔 안 잡혀서, 사용자의 8081 포트 dev 서버는 건드리지 않고 별도 포트(8099)로 임시 서버를 띄워 Expo Router 타입 캐시만 갱신한 뒤 종료했다
- `npx expo lint` 통과
- 같은 임시 서버로 `curl` 확인: `/notifications`(기본 진입 시 알림 탭 콘텐츠인 "캠퍼스 가이드" 텍스트 확인), `/notifications/settings`(알림 설정/채팅 알림/서비스 알림/담당자 1:1 채팅/시스템 안내 전부 확인) — 두 라우트 모두 HTTP 200, 에러 마커 없음

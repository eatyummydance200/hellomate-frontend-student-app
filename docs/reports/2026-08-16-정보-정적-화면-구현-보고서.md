# 정보 정적 화면 구현 보고서

## 배경

Phase 4(정적 화면 퍼블리싱) 네 번째 배치로, Figma `hellomate-workspace` 파일의 정보 화면 그룹(노드 `56:221`)에 속한 화면 전부를 API 연동 없이 더미 데이터로 하드코딩 구현했다. 그룹은 3개의 최상위 프레임(정보 홈, 정보글 상세, 정보 수정 요청)을 담고 있었다.

| Figma 프레임 | 실제 구현 | 구현 파일 |
| --- | --- | --- |
| 정보 홈 (24:1099) | 목록 화면 | `app/(tabs)/info.tsx` |
| 정보글 상세 (24:1210) | 상세 화면 | `app/info/[id].tsx` |
| 정보 수정 요청 (24:1298) | 바텀시트 모달 | `app/info/edit-request.tsx` |

## 화면 통합 판단

- **정보 수정 요청** → Figma 프레임을 열어보니 [[project_club_screens]]의 "클럽 가입완료"와 같은 패턴이었다: 정보글 상세 화면 위에 반투명 배경 + 하단 바텀시트가 얹힌 모달 목업. 별도 전체화면이 아니라 `app/info/edit-request.tsx`를 `presentation: 'transparentModal'`로 등록해 구현했다(`app/info/_layout.tsx`).

## 화면별 구현 내용

### 1. 정보 홈 (`app/(tabs)/info.tsx`)

- 기존 자리표시자(`정보`/알림 링크 텍스트만 있던 화면)를 실제 화면으로 교체, 공통 `Header`·`BottomNav` 적용 — 이번 배치로 정보 탭도 [[project_club_screens]] 때와 같은 이유로 실제 네비게이션 쉘을 갖추게 됨
- 히어로 배너(도시 사진 + 그라디언트 오버레이 + "CITY GUIDE" 태그 + 제목) — 캐러셀 인디케이터 4개 중 첫 번째만 활성 색으로 고정(Figma가 정적 프레임이라 실제 슬라이드 전환 로직은 없음)
- "생활정보" 섹션: 카드 5건(제목 + 날짜 + 조회수), 카드 클릭 시 `router.push({ pathname: '/info/[id]', params: { id } })`로 상세 이동

### 2. 정보글 상세 (`app/info/[id].tsx`)

- 자체 뒤로가기 헤더("정보글") + 본문 카드(제목/업데이트일 + 핵심 안내 배너 + 4단계 가이드) + 예상 수수료/처리 기간 2분할 카드
- 4단계 가이드는 번호 원 + 세로 연결선(마지막 단계 제외) 구조를 [[project_club_screens]]의 배지 패턴과 유사하게 반복 렌더링. 2번째 단계에만 태그 칩(`#재학증명서` `#체류지입증`)이 붙어 있어 `step.tags`를 옵셔널로 처리
- 하단 버튼 2개: "정보 수정 요청하기"(outline, `/info/edit-request` 모달로 이동) / "링크로 접속하기"(primary, Phase 4라 실제 외부 링크 연결 없음)
- `id` 파라미터는 [[project_notice_screens]]·[[project_club_screens]]와 동일하게 아직 미사용 — Figma 시안 내용을 고정 출력

### 3. 정보 수정 요청 (`app/info/edit-request.tsx`)

- [[project_club_screens]]의 "클럽 가입완료" 모달과 동일한 뼈대(반투명 배경 탭 시 닫힘 + 하단 바텀시트)
- 대상 정보글을 보여주는 컨텍스트 박스 + "수정 내용" textarea(500자 제한, 실시간 글자 수 카운터는 `useState`로 동작) + "전송하기" 버튼(Phase 4라 실제 전송 없이 `router.back()`만 수행)

## 에셋

Figma MCP 에셋 URL에서 아이콘 8종 + 히어로 사진 1종을 새로 받아 커밋했다: `icon-calendar-sm`, `icon-eye`, `icon-calendar-xs`, `icon-info-circle-sm`, `icon-fee`, `icon-duration`, `icon-document-sm`, `icon-send-arrow`(`assets/icons/`), `info-hero.jpg`(`assets/images/`). 뒤로가기 화살표와 알림 종 아이콘은 기존 `icon-chevron-left.svg`·`notification-bell.svg`를 그대로 재사용했다(공지사항/클럽 상세 화면과 동일한 글리프로 확인).

## 토큰 결정

이번 배치는 새로 등장한 색상 대부분이 기존 토큰과 정확히 일치했다: `primary`(`#006b55`), `primary.light`(`#49c9a7`, 배너/컨텍스트 박스 배경), `text.strong`(`#171d1a`), `background.muted`(`#e9efeb`, 태그 칩 배경), `border.strong`(`#bccac3`, 카드 테두리/텍스트 영역 테두리). [[project_notice_screens]]에서 확정된 방침대로, 일치하지 않는 값(본문 보조 텍스트 `#595c7e`, 세로 구분선 `#414465`, 안내 텍스트 `#414465`, 인디케이터 활성색 `#575c83`, 연결선 `#dee4e0`)은 인라인 임의값(`text-[#595c7e]` 등)으로 처리했다. `tailwind.config.js`는 건드리지 않았다.

## 검증

- `npx tsc --noEmit` 통과 — 신규 라우트(`/info/[id]`, `/info/edit-request`)가 타입에 아직 안 잡혀 처음엔 에러가 났는데, Expo Router 타입은 dev 서버가 `app/` 디렉터리를 스캔해야 갱신되는 캐시 파일(`.expo/types/router.d.ts`)이라 그렇다 — 사용자가 이미 8081 포트로 실기기 연결된 dev 서버를 띄워두고 있어 그 프로세스는 건드리지 않고, 별도 포트(8099)로 임시 서버를 띄워 타입만 갱신한 뒤 종료했다
- `npx expo lint` 통과
- 헤드리스 브라우저가 없어 같은 임시 서버로 `curl` 확인: `/info`(정보/CITY GUIDE/기사 5건 제목 전부), `/info/i1`(D-2 비자 연장 완벽 가이드/만료일 확인/예상 수수료/정보 수정 요청하기), `/info/edit-request`(수정 요청 보내기/대상 정보글 제목) — 전부 기대한 한글 텍스트 포함 확인
